# 默认档位表

行业默认档位的聚合表：**B1 摆出来给用户点头用这份，阶段 C / E 写 token 引用这份**。使用规则：

- 项目还没有自己的一套时直接用；项目已有自己的一套就沿用项目的，把差异记进项目文档。
- **问法是「给默认值 + 让用户点头」，不是「你想用什么值」**；一次问清一整组，别拆成十几题（见 B1）。
- 覆盖默认要留记录（偏离了什么、为什么），不许静默打破（工作前提 7）。

## 间距 —— 8px 节奏，4 只作半拍

| 值 | 用在哪 |
|---|---|
| 4 | 半拍：图标与文字之间、标签 / 徽标的内距 |
| **8** | **默认节奏**：控件与控件之间、行内间隙 |
| 16 | 组与组之间、卡片内距 |
| 24 | 模块与模块之间 |
| 32 | 页面级留白 |
| 48 | 仅当确实需要大留白（没有一处需要就不建这一档） |

- 不取任意 4 的倍数（12 / 20 / 28 不在网格上）；不为「凑完整」补没人用的档位——token 表里每一档都要能指出至少一个在用之处。
- 控件尺寸分两说：**高度**取网格（与内距同一把尺）；**宽度**由内容与所在栅格决定，不受网格约束（网格里没有够用的宽度档，硬凑会把内容挤变形）。

## 字号 —— 正文基准 14（阅读型产品用 16），下限 12

| 值 | 角色 |
|---|---|
| 12 | **最小档，全站下限**：表头、注释、次要标签、微型标记（标签 / 徽标 / 角标） |
| **14** | **正文基准**（数据密集型工具；阅读型产品用 16） |
| 16 | 卡片标题、按钮、页面标题 |
| 18 | 模块标题 |
| 20 | 数值小号 |
| 24 | 大数值（KPI 数字） |
| 28 | 特大数字（概览大卡） |

取 4 的倍数，无合适档再取 2 的倍数；不出现 11 / 13 / 13.5 这类散值。

**12 是硬下限，别为「微型标记」再开一档 10px**：低于 12px 在 Windows 上渲染发虚（ClearType 在 12px 以下对中文字形的 hinting 开始失效），且 12px 是行业通用下限。微型标记（标签 / 徽标 / 角标）用 12px 完全撑得住——**如果标记在 12px 下显得挤，那是内距或字重的问题，不是字号该再往下走**。

## 行高 —— 倍数随字号反着走，只有三档

| 场景 | 倍数 |
|---|---|
| 大标题（≥ 20px） | **1.2** |
| 正文 | **1.5**（长段落可到 1.6–1.8） |
| 单行控件（按钮 / 输入框 / 下拉项 / 徽标） | 1.4 |

- 「越大越小」说的是**倍数**——绝对行高永远随字号变大。字号大了字形整体就高、笔画就密，再给足行间余量整块会散。
- 单行控件的行高不查字号表：单行的行间余量看不见，却会直接把控件撑高，按「控件高度的一部分」理解，且**别漏写**（见 P1）。

## 字重 —— 按字体实际可用的字形档数定档

| 值 | 用在哪 |
|---|---|
| 400 | 正文（**不写就是 400**，不必显式设一档） |
| 500 | 强调、次级标题 |
| 600 | 标题、表头 |
| 700 | 仅少量强强调 |

字体只有「常规 / 粗」两档字形时就用 400 / 700 两档——**设超过字体能力的档等于写下不生效的规则**（也解释了「为什么这里加粗看不出来」）。

## 圆角 —— 四档 + 全圆只给药丸

| 值 | 用在哪 |
|---|---|
| 4 | 微型标记、行内小片 |
| 8 | 按钮、输入框、下拉、菜单项、浮层 |
| 12 | 卡片、面板 |
| 16 | 大容器（上传区、空态卡） |
| 999（全圆） | **只给药丸**：徽标、状态点、分段条、进度条 |

别名只做「按用途起名」的引用，指向上面的档位——**改档位只动原始行，别名不写死值**。

## 图标尺寸 —— 五档（标称视口，实际墨迹比它小一号）

| 档 | 值 | 角色 |
|---|---|---|
| 内嵌 | 14px | 嵌在别的控件里，或旁边是更小的控件 |
| 行内 | 16px | 按钮内、菜单项、表格工具 |
| 独立 | 18–20px | 导航、模块标题旁、自占一格 |
| 状态 | 20–24px | 提示条、状态指示 |
| 大图标 | 40–48px | 空态、上传区（装饰，不是控件） |

## 阴影 —— 三档

| 档 | 用在哪 | 强度方向 |
|---|---|---|
| 卡片 | 静止卡片 | 极淡、**四向均衡**——用「底部两层给方向感 + 对称两层把上 / 左 / 右补平」的组合，只留底部会像「只有下边有影」 |
| 浮层 | 弹窗 / 菜单 / 悬浮条 | 偏移与晕影比卡片大一档（层越高影越开） |
| 贴触发器小面板 | 下拉 / 筛选弹窗 | **比浮层更淡**（用浮层那档会在浅色页面上像浮在半空、和按钮脱节） |

数值是方向，不是必须照抄的常数。深色模式下阴影基本不可见，**改用描边分层**（常见做法是把阴影直接设成 `none`，只留最浅档描边）。

## 动效时长 —— 三档

| 档 | 值 | 用在哪 |
|---|---|---|
| `fast` | **150ms** | 按下反馈、悬停变色、图标切换 |
| `base` | **220ms** | 提示 / 小浮层、下拉展开、页面内容入场 |
| `slow` | **300ms** | 弹窗 / 抽屉、面板、图表入场 |

- **`slow` 的 300ms 就是上限，别再往上加**——越快越像「立刻」。
- 常见参考区间（按下 100–160 / 小浮层 125–200 / 下拉 150–250 / 弹窗 200–500）是**放宽范围**：在区间内**优先落到上面某一档**，别真的用 500ms。
- 循环动画（转圈、呼吸）的周期不进这三档，按观感定。

## 缓动 —— 场景 → 曲线

| 场景 | 用哪条 |
|---|---|
| 进场（出现、展开） | `cubic-bezier(.215,.61,.355,1)`（≈ easeOutCubic）——项目里**唯一的「进场」token** |
| 屏上移动 / 形变 | 内置 `ease-in-out` |
| 悬停、颜色变化 | 内置 `ease` |
| 退场 | 同进场曲线，但**时长比进场短一档** |
| 匀速运动（进度条、跑马灯） | 内置 `linear` |

其余缓动规则（禁止 `ease-in` 进场、过陡的上限、多套实现必须同族）见 `design-grammar.md` 的 G5。

## 点击目标

可点元素高度 ≥ 24px，主要目标（下拉 / 弹窗按钮）≥ 32px，触屏 44×44（见 G3）。破例的写明理由（如「另有等价键盘路径」）。撑法见 G9。

## 层级 z-index —— 五带

| 带 | 值 | 用途 |
|---|---|---|
| 粘性 | 10 | 粘性顶栏、表头、常驻侧栏 |
| 浮层 | 100 | 下拉、菜单、筛选弹窗 |
| 遮罩 | 900 | 全屏遮罩 |
| 模态 | 1000 | 抽屉、弹窗 |
| 提示 | 1100 | Toast（永远最上） |

- 项目用不到某带（如没有模态）就不建那个 token；带内要细分时用 10 步长（100 / 110 / 120）。**别用 1 / 2 / 3 这种连号**——插一层就得全改。
- 重排既有层级时**先确认相对顺序没变**，只把间隔拉开。
