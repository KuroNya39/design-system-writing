# B1 深度取舍讨论（细则）

进入 B1 前读完。B1 的目标不是「问几个问题」，而是**把审美方向问透，让后面写规范时不必猜**。

## 怎么推进

把待定事项看成**决策树**：一个决定会分出挂在它下面的新决定。按**轮**推进——**前沿**是前置条件已定、此刻不必猜答案就能问的那些问题。一轮把前沿一次问完，每题编号并给出推荐答案；用户答完重算前沿，再问下一轮。**未定项清空即进 B2。**

**「一轮 ≤ 5 题」是每轮额度，不是总题数。默认至少走两到三轮。** 只问一轮就进 B2，通常意味着漏了整块决策面：只问风格、没问密度；只问主色、没问分类色板与深色范围；只问图标库、没问图标与文字同行怎么对齐。

## 问透判据（三条都做到才算了解用户）

1. **能复述**：用三句话说出用户要的视觉方向，他会点头说「对，就是这个意思」。
2. **能说出他不要什么**：知道他会讨厌什么。**负面清单往往比正面更定方向。**
3. **能预判下一个问题**：你知道他面对「圆角大一点还是小一点」会往哪边选。

## 追问含糊的回答，别自己填

用户答「你看着办」「专业点就行」「高级一点」——这些**不是答案**，是他还没有具体想法。给他 2–3 个具体选项让他挑（「A 是紧凑工具型，B 是留白大的展示型，你更接近哪个？」）。**选项拿真实产品举例**，比形容词好懂。

**问参考物是摸审美的捷径**：「有没有你用着顺手的界面 / 产品 / 截图？」——一张参考图胜过十个形容词；有就按它取证（配色、密度、圆角、动效量级），没有就用选项法。

## 候选风格（只在入口 ①、且 B0 判为「大改」时给）

小改、取约束、审界面**不给**——小改的风格与排版不动，给了只会诱导扩大范围。

先问三个以内的问题把方向框住：① 有没有顺手的参考产品？② 谁在用、一天用多久？③ 明确讨厌什么？**了解完再生成 3–5 个候选**，别一上来抛一片。

**候选之间必须真的不一样**：任意两个至少在六个维度中的三个上不同——气质、密度、主色策略、形状语言（方正 ↔ 圆润）、排版声量、动效量级。只换配色不算候选，那是同一个方案的五件衣服。

**每个候选写四行**（写定性取向，不写具体数值——数值只在 `defaults.md`，两处写迟早对不上）：

- 气质一句话
- 适合什么（产品形态 / 使用频率）
- 代价是什么（这个方向会让什么变难、牺牲什么）
- 关键档位取向（间距松紧、字号基准、圆角形状、主色策略、动效量级）

**呈现**：默认文字卡片，对话里就能判断。用户说「想看看实际效果」时，再出一张**单页 HTML 拼贴板**——① 同一批组件实例，只换气质参数；② 一次性并排、不做交互；③ 只呈现不推荐，选哪个由用户说。

**用户回应后的四种走法**：

| 用户说 | 怎么做 |
|---|---|
| 挑一个 | 直接成为 B2 目标方案的基底 |
| 「A 的密度 + C 的主色」 | 按他点名的维度合成一个新的，别自己再加料 |
| 都不满意 | 换一批（**上限 1 次**）；仍不满意就收敛到 2 个让他二选一 |
| 说不清 | 收窄到 2 个，用「你更接近哪个」逼出一个判断 |

## 提问格式与推荐答案

```
❓ **Q1** - **<问题标题>**：<问题正文，可多段，可列选项>

➡️ <你的推荐答案>
```

**推荐答案要带依据**（「从 A4 的使用情境看…」），依据来自本项目取证；没有依据就说清这是猜的。给快车道：回复「全按推荐」即按默认走。

**问题数量只有一条校准标准：这个答案会不会改变你接下来写的东西？** 不会的自己定、交付时说明即可。

- **太重**：问了自己查得到的（对比度、某枚图标有没有）；问了依赖同一轮其他未答项的题；把 B0 和 B1 混在一轮；一轮超过 5 题。
- **太轻**：只问一轮就收工；开工后才发现范围没定；审美方向全靠猜；该给候选时只抛一个方向；用户答「看着办」没追问就自己填了。

## 有默认值的档位

照 `defaults.md` 摆出来问一句——问法是「给默认值 + 让用户点头」，不是「你想用什么值」。一句「间距按 8 网格、正文 14px 行高 1.5、圆角 4/8/12/16、动效 150/220/300ms，就按这套来？」已经够用户判断；**一次问清一整组**，别拆成十几题占满额度。项目已有自己的一套就沿用项目的，把差异记进文档。

## 必问清单

**★ 必问（问不到就别往下写规范）**

- **改动幅度与方向**：大改还是小改——B0 已问，B1 里用来决定问多细。
- **视觉气质与密度**：克制工具型（密度适中、低修饰）/ 品牌展示型（留白大、一枚强主色）/ 数据面板型（紧凑、tabular、弱化装饰）。这是「风格」的总开关——它决定间距、字号、留白、装饰与动效量级，**不能从产品类型直接推**（同一个后台，有人要信息密，有人要留白多）。答得含糊就生成候选再挑；用户一上来给了参考物，可跳过三型直接出候选。
- **图表库选型**（见 G11）：一旦定了，所有配置写法、动效口径、配色取用都跟着它走，中途换库等于重做。同时定图表动效走哪档、配色是否复用页面分类色板。
- **图表风格**：轻网格（去纵轴、弱网格线）/ 完整坐标系（精确读数）/ 极简 sparkline。
- **主品牌色**：从 A3 / A5 找现有 accent 候选，附对比度检验；多枚在用就收敛到语义上最重要的那一枚。
- **图标库选型**（选哪套、统一到哪个风格档）——尺寸档位不问，走默认五档。
- **动效胃口**：几乎不动 / 克制（只在浮层与状态切换）/ 有存在感。——时长与缓动的具体档位不问，走默认。

**○ 按需**：圆角与密度胃口（只问「方正还是圆润」这一层，具体档位不问）；深色模式 / 缩放 / 主题化范围；触屏是否在目标设备里（决定命中区档位）。
