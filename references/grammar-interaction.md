# 设计语法 · 交互与动效（G3、G4、G5）

规则集分四册，G 编号跨文件连续。本册管输入、状态与动效；流程与文案见 `grammar-flow.md`，视觉见 `grammar-visual.md`。默认档位在 `defaults.md`。

## G3 交互与输入
| 语法 | 落地检查 |
|---|---|
| **先定主输入**（鼠标 / 键盘 / 触屏）：按主输入设计，其余「可用」即可。 | 说得出主输入是什么，主路径对它最顺手。 |
| **命中目标不小于 24×24**（触屏 44×44）：视觉可小，可点区不能小。 | 过一遍最小控件（撑法见 G9）。 |
| **按下即反馈**：反馈挂在 `pointerdown`，不是 `click`。 | 按住不放，是否已经变样。 |
| **瞬时提示从最后一次交互起算**：会自己消失的「已保存」类提示，每触发一次重新计时。 | 连点三次，提示是否每次都重新计时。 |
| **悬停只是增强**：不能用悬停承载唯一入口或唯一信息。 | 移开鼠标，功能与信息是否仍可达。 |
| **一个手势一次**：手势进行中忽略后续触发点。 | 拖动中再按一根手指，位置是否跳。 |
| **拖拽 1:1 跟手并尊重抓取点**：从哪儿按住就从哪儿算偏移，不吸附中心。 | 从元素边角按住拖，是否从边角跟手。 |
| **阈值之后才算拖拽**：小位移当点击（约 4–10px 后才进入拖动）。 | 轻微移动后松手，是否仍算点击。 |
| **键盘是一等公民**：Tab 顺序 = 视觉顺序；Enter / 空格激活；组内方向键；Esc 取消。 | 全程只用键盘完成一次主任务。 |
| **焦点有家可回**：弹窗内锁焦点，关闭还给触发元素；删掉元素后焦点移到合理邻居。 | 开 → 关弹窗、删一行，各看一次焦点落点。 |
| **可中断**：进行中的过渡、动画、加载能被新输入打断，并从**当前值**继续。 | 关到一半再点开，是否从当前位置接管。 |
| **输入约束在所有输入路径生效**：点加减、方向键、手输、粘贴四条路都得管。 | 四条路径各输一次越界值。 |
| **危险动作物理隔离**：不与主行动相邻（见 G8）。 | 主 CTA 旁边不是删除。 |

**表单**
- **每个字段有常驻标签**：不要只用 placeholder 当标签（输入后它就没了）；必填标记与可选说明写清楚。
- **校验时机**：失焦校验单个字段，提交校验全部；不要在每敲一个字时就报错（该字段首次报错后可改为实时校验）。
- **错误提示紧贴字段**：写在字段下方，说清缺什么、怎么改；提交失败把焦点送到第一个出错的字段。
- **字段顺序按填写逻辑**，不按数据库字段顺序；相关字段成组。
- **主按钮放在表单末尾且不随滚动跑**；长表单分段，段内一屏能填完。

## G4 状态模型（完整状态组）

> **核心规则：任何可交互组件定义完整状态组**——按钮至少 默认 / 悬停 / 按下 / 加载 / 禁用 五态；输入框、卡片、开关、菜单项同理，另按需补 键盘焦点（focus-visible）、选中（selected）。

- 状态词汇统一：`rest`（静置）`hover` `active`（按下）`focus-visible`（键盘焦点环）`loading` `disabled` `selected`。
- **焦点环只在键盘到达时显示**（`:focus-visible`），鼠标点击不显示。
- **禁用** = 禁用底色 / 禁用字色 + 禁用光标 + 去阴影。

**按压反馈**
- 可整体缩放的控件（按钮、分段钮）按下 `scale(.97–.98)`；整行、菜单项、折叠头这类**行级元素用按下底色**，不整体缩放以免内容破碎。
- **按下不单独给色**，统一交给缩放——省掉「悬停变浅、按下又变深」的方向来回。
- **唯一例外是主 CTA**：它悬停往「加深」走，按下再深一档同方向。**这条例外只属于这一枚**，别的按钮照搬会出现「有的变深、有的只缩一下」。
- 拖动 / 长按路径上的按下观感**不能靠 `:hover`**（见 P2），由脚本挂状态类。

**悬停总则：浅底加深、深底变浅**（所有有底色的可点面：按钮、下拉项、列表行、菜单项。）
- **按 `cursor:pointer` 扫，不按「长得像不像按钮」**：卡片、整块可点区、缩略图、可点图表元素都算。最常见翻车是「按钮统一了、可点卡片各写各的」。**检查**：全站 grep `cursor:pointer` 与绑了 click 的容器，逐个归类，归不进的就是漏网的第三类。
- **只改底色，不上浮、不加悬停影**：浅底加深一档，深底变浅一档。
- 洗涤档位成阶梯、档间等差。**按下取「松手后会变成的样子」**（选中档），不跳过中间档——按下即预览结果。
- **有底色的改底色，没底色的改自身颜色**，方向都是往更醒目一档。
- **状态底色层与色阶可以并存**：有自己的方块点击区就铺底 + 加深；嵌在别的控件里的小图标只加深不铺底。判断标准是**有没有自己的方块点击区**。

**图标控件的状态色**（适用于「一枚图标自己就是个控件」的地方。）

四态从**同一条灰阶阶梯**取，阶梯做成 token，**定义只在一处**，组件只引用、不写字面量。

| 态 | 取值方向 |
|---|---|
| 静置 | 基准灰 |
| 悬停 | 深一档 |
| 按下 | 再深一档 |
| 禁用 | **反方向退到更浅**（比静置还浅） |

- **禁用是「退到后面去」，不是「更醒目」**。用更深的灰会让禁用态比静置还显眼，只能再压 `opacity` 补救——那是把补丁当设计。**不要用 `opacity` 表达「淡」**。
- **只加深，不变色相**；**整族共用一个底座**：同类图标控件共用一个基类，新增时挂进已有的族，不重抄四档。
- **图标控件不带语义色**：破坏性操作靠图标字形 + 确认弹窗承担。
- **展开态 ≠ 悬停态**：展开时的高亮属于「选中语义」，不在悬停阶梯里。

**加载与选中**
- **loading**：加载中的按钮 = 前置转圈 + **真正的禁用**（置灰、鼠标键盘都点不动），**文字保持不变**——不改成「正在… / …中」。开关逻辑抽成一个函数（记住进入前的禁用状态、结束时还原），才能与「按条件禁用」叠加。
- **selected**：选中态 = 底色 + 强调字双信号，不只变一个色。

**状态指示必须来自真实状态**
- 进度条、完成标记、状态标签一律由**真实状态**推导，不用间接信号顶替——「某个文件在不在」「上一帧剩下的值」「默认值」在真实状态发生前就已成立，指示会**提前点亮**。这比不亮更糟：用户据此以为已经好了，然后对着一个没反应的界面等。
- 反方向同样要防：真实状态已结束（完成 / 失败 / 被取消）时，指示必须跟着结束。
- **检查**：拿「还没开始 / 进行中 / 已完成 / 失败」四态逐个走一遍。

## G5 动效（Motion）

**先答「该不该动」，再谈怎么做。**

| 这个操作一天发生几次 | 判据 |
|---|---|
| 上百次（快捷键、命令面板、高频切换） | **不动画。永远不动。** |
| 几十次（悬停、列表内移动） | 去掉，或压到几乎察觉不到 |
| 偶发（弹窗、抽屉、Toast、二级页） | 正常做 |
| 罕见 / 首次（引导、完成、庆祝） | 可以加一点惊喜 |

**键盘触发的动作一律不做动画**——它一天会发生几百次，动画只让它变慢。

**每个动效要能说出目的**：空间一致性（进出同源）/ 状态指示（变了什么）/ 解释（这东西怎么用）/ 反馈（听见了你的操作）/ 避免突兀。**说不出目的的就是装饰**，高频场景里不要。

**缓动治理**（档位见 `defaults.md`）
- 只有「进场」这条曲线需要自定义（`cubic-bezier(.215,.61,.355,1)` ≈ easeOutCubic），其余用内置关键字——手写的越多越容易分家。
- **禁止用 `ease-in` 进场**：开头慢，而那一瞬正是用户盯得最紧的时候。
- **「更陡」有上限，过陡的 ease-out 就是「突兀」本身**：内置 `ease-out` 偏弱；easeOutCubic 是目标档；easeOutExpo 前 15% 时间就走完九成距离，看到的是「啪」一下。
- **突兀的观感多半来自曲线，不是时长**：用户报「太快 / 太突然」时**先查曲线陡不陡**。
- **全站只留一条进场曲线**（一个 token）。
- **多套动效实现必须同族**：CSS、图表库（如 Chart.js 的 `easing`）、JS 动画库三者的缓动取自同一族同一档；改一处必须同步另一处，审计时两边对账。

**空间与形态**
- **遮罩与内容同拍**：遮罩和面板同起同落、同时长。只给面板配动效、遮罩直接切，会出现「背景先黑、面板后到」。
- **进出同路径**：从右边进来的就从右边出去。
- **浮层从触发它的元素长出来**：`transform-origin` 指触发点；**弹窗例外**，居中即可。
- **不要从 `scale(0)` 出现**：起点用 `scale(.95)` 配 `opacity: 0`，或用位移。
- **进出场要「有方向」**：每一帧都该暗示最终去哪儿。

**实现选择**
- **用 transition，不用 keyframes**：transition 能中途打断并改目标，keyframes 只能从头重放；keyframes 留给循环动画。
- **只动 `transform` / `opacity`**：改宽高、内外边距、`top / left` 会触发布局与重绘。
- **动效 token 要拼好给人用**：给时长与缓动档位，再给「拼好的组合」（如 `transition-fast`），不让人自己拼。

**交接与降级**
- **速度要交出去**：拖拽结束后的动画接着手指离开时的速度走，不要硬切到固定时长。
- **减少动效不是取消反馈**：`prefers-reduced-motion` 下把位移 / 弹性降级成短淡入淡出。
- **浮层之间互切要交叉过渡**，不留「只剩空遮罩」的那一帧（见 P6）。
