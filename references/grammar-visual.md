# 设计语法 · 视觉（G6–G10）

规则集分四册，G 编号跨文件连续。本册管度量、色彩、组件几何、图标与造型；流程见 `grammar-flow.md`，交互见 `grammar-interaction.md`。**档位表在 `defaults.md`，本册只留治理规则。**

## G6 度量治理（档位见 `defaults.md`）

- **由几何反推的值必须写明出处**（如「为了让 A 与 B 对齐算出来的数」）：改了就会错位，不写出处会被当成随手写的裸值清掉。
- **能用对齐方式做到的，就别用负外边距**——它会连点击区、悬停底色一起推出内容列。两类正当除外：把「撑大的点击区」缩回原占位；给滚动容器留焦点环余量（见 P4）。每处写明属于哪一类。
- **间距同时承担成组**：同组内小档、相关组间中档、页面级大档。想让某元素重要，就放大它周围的间距——**分组靠间距，不靠画线**。
- **不单设「中标题 1.3」行高一档**：真觉得 1.2 挤，说明该调字号或间距。
- **改行高 token 前先查它推导出了哪些几何**：控件高度、图标按钮边长可能全由它算出来，旁边要写明「改它要重算哪些」。
- 数字数据（分数、计数、进度、统计）一律 `tabular-nums`。
- **只有多行长段落才两端对齐**；短句与单行输入框不加（单行永远算「最后一行」，加了也看不出变化）。
- **加粗用少才有效**：需要层次时优先字号与灰阶；一屏内加粗处应当一眼数得清。
- **不要把「选中」这类状态信号压在字重上**：小字号下常规与加粗的差异不足以承担状态（选中态走 G4 的底色 + 强调字）。
- **不追求大圆角，也不要 0 直角**（理由见 G10）。

## G7 色彩系统（语义驱动）
| 语法 | 落地检查 |
|---|---|
| **色板分三层**：中性灰阶（打底与文字）+ 语义色阶（唯一 accent + 成功 / 警告 / 错误 / 信息）+ 档位色阶（评分星、等级这类有序档）。各司其职，不互借。 | 每层能指出职责；档位色没被当操作色。 |
| **颜色全部来自色板 token**，无语义挪用（绿不表达错误、红不作成功）。 | token 之外无裸 hex / rgb；语义映射固定且唯一。 |
| **语义族成套**：每族给 浅底 / 边框 / 本体 / 深字（需要叠透明度再补 rgb 三元组）。**缺一档就会出问题**——没有深字档时，浅底上的字只能退回本体色，而本体色按白底校准，垫一层洗涤后跌到达标线下。 | 语义 token 命名成族；对照度表逐族核过。 |
| **底与字分工**：色块 / 进度 / 按钮底用本体色；**坐在自家浅底上的文字必须用深字档（strong）**。 | 白底档位 / 状态文字引用 strong 档。 |
| **对比度按「实际所在底色」校准，不是按白底**：同一个灰 / 色垫到浅底上会掉一档。 | 关键文字对用它**真正坐在上面**的底色算过。 |
| **命名要能自解释**：同族里「浅一档（给实心底悬停用）」与「深一档（给浅底上的字、描边悬停用）」并存时，名字必须一眼分得清方向。 | 看到名字不必回文档就能判断方向。 |
| **语义提示用「浅底 + 深字」双通道，不配语义描边 token**：轮廓线交给留白。 | 语义族只有三档，没有语义 `--border-*`。 |
| **档位色只作档位**，不作操作色 / 警示色；警示走警告或错误。 | 档位色不出现在按钮与提示条上。 |
| **主 / 次 / 危险按钮**：主行动 = 主色实心；次要 = 描边 / 幽灵；危险 = 红实心仅限破坏性确认位。一屏一个实心主按钮。 | 主 CTA 视觉最实；危险动作不贴主 CTA。 |
| **状态不只靠颜色**：错误 / 必选 / 选中等在变色之外必须有图标或文字。 | 错误输入 = 红描边 + 提示语；必选 = 标记 + 校验提示。 |
| **对比度底线**：正文与重要标签 ≥ 4.5:1，大字 / 粗体 ≥ 3:1。 | 关键文字对用对比度工具算过。 |

## G8 组件几何

**按钮：身高定字号，文字不「撑」按钮**
- 控件高度决定内部能放多大的字。经验比例：按钮字号 / 按钮高度 ≈ **0.39–0.44**，越大越接近上限；**超过约 40% 就该加高度**，不是把字塞进矮按钮。
- 字号表里最大的两档**不进按钮**。
- 按钮内图标比的是**墨迹**不是盒子：**墨迹高 ≲ 字号 × 1.1**，与文字间距 ≥ 4px。（图标库画布自带留白，按盒子边长卡这条会误判。）

**按钮排列：鼓励靠右、危险靠左**
- 普通动作（保存 / 确定 / 开始）：主动作放**最右**，取消在左。
- 危险动作（删除 / 清空）：放**偏左**，与主 CTA 拉开——**但「偏左」不必然是第一个**，排第二也行，只要不在最右。
- 鼓励动作视觉更实（实心主色），不与危险按钮做对称样式。红实心只出现在确认弹窗的破坏性「确定」位。
- **底部操作区只有一个按钮时贴右**：不论它是危险还是关闭类动作，靠左留空会被读成「少放了一个按钮」。双按钮才讲「取消在左、主 / 危险在右」。
- **间距是「盒子相等」，视觉上并不相等**：可点区是盒子、图形只占中间的图标钮，与紧邻的实心 / 描边控件之间视觉间距会被吃掉。按墨迹宽两侧各校正一档。
- **当前批次不能删除时，按钮照常占位走禁用态**：只删按钮会让每行末端结构不一致、图标位置来回跳；禁用理由写进 `aria-label`。

**其他**
- **只读展示不许长得像可输入**：只读值用更弱的底、无描边、辅助字色、更小字号，比相邻输入框明显弱一档；长值省略号收尾。
- **弹窗内容多时只在自身高度内滚动**，标题与底部按钮固定不动；滚动区留焦点环余量见 P4。
- **提示条用语义浅底 + 深字，不带描边**；底色取语义 token，不手写半透明洗涤。
- **空态要有**：居中、辅助字色、多行说明用舒展行高（内容要求见 G2）。
- **相邻可选项之间要留缝**：下拉项、分段钮两片同色底相接就糊成一块；留一条缝，或让底色圆角收进去。

## G9 图标规范

**选型**
- **按产品类型与平台选一套图标库并固定**（线宽风格、权重档、许可）。同一产品只用同一套功能图标，同一套库内只取同一风格档。
- **尺寸、线宽、间距统一**（做成 token）；**档位绑死角色**，按角色选、不按「看着差不多」选。
- **标称尺寸普遍比文字大一号**：图标库画布按统一格数归一化，墨迹只占一部分、四周自带留白。拿标称值对字号会一直觉得别扭（默认五档见 `defaults.md`）。

**对齐**
- **对齐比的是墨迹，不是盒子**：判断用「高」不用「宽」；同一行几枚图标墨迹占比不同时，允许同档内小幅微调，目的是**墨迹等高**。每处微调写明理由。
- **图标与中文同一行时，对齐文字的「墨迹中线」**：中文在行框里比中线略低，只做盒子居中会让图标偏高半个像素。给该行图标一个随字号走的光学补偿，不是撑高图标盒、也不改行高。
- **对齐要量，不要目测**：`getBoundingClientRect()` 取图标墨迹中线与相邻文字行框中线相减，**差值 > 0.5px 就算没对齐**。同一行多枚图标时，先保证彼此墨迹等高，再一起对文字中线。
- **菜单项、下拉项这类「行」不受按钮比例约束**：整行高度和留白可用，图标可取大一点；只有**按钮内**图标守 G8 的比例。

**实现**
- **图标统一进 symbol 库 / 图标组件**，界面不散落路径。
- 调用处的视口尺寸与库内部坐标系是两件事——符号库会缩放适配，**调用处照常写常规视口**。官方路径一个字符都别手改。
- **实心 / 空心的判据是「这枚字形有没有能看的细线版」**，不是「它重不重要」：播放三角、暂停双杠本身是实心几何，取线形只会得到细描边、小尺寸糊成一团。新增实心图标先确认落在「本身没有可读线形」或「需要重一级的强调」两类里，并写明理由。
- 颜色跟随 `currentColor`；方向箭头由 CSS `rotate()` 转向，不写字形字符。

**点击目标**
- **不小于 24×24**：图标可以只有 12–18，可点区要撑到 24（触屏更大，见 G3）。两种撑法：直接做够大的盒子；或做大盒子再**配负外边距把占位缩回原尺寸**。
- **浮层要锚在被锚元素盒子的「中线」而不是边缘**：中线与盒子尺寸无关，盒子改多大偏移都正确（见 P9）。

**禁止**
- 禁止 Emoji 当功能图标（跨端渲染不一致）；禁止用 Unicode 字符代替图标（▸ ▾ ✔ ❌）；禁止临时生成内联 SVG 当图标。
- 找不到图标时选同库近义图标，不为省事退回字符或自绘。
- 不用 `opacity` 表达「淡」，走状态色阶梯（见 G4）。

## G10 造型口味（默认，可被 B 覆盖）

默认阴影三档见 `defaults.md`。治理规则：
- **阴影承载浮起层级，不作装饰**：中性暗调、低透明，宁浅勿深。
- **浮层描边取最浅档**：分层交给阴影，描边只勾边界。
- 深色模式下阴影基本不可见，**改用描边分层**。
- **状态发光是唯一例外**：状态点光晕、选中高光、主 CTA 悬停影用语义色叠低 alpha，表达「发光 / 选中」，不是浮起层级。**除主 CTA 外，按钮悬停不给影**（见 G4）。
- **圆角克制**：不做超大圆角、不做 0 直角；不做高饱和渐变、不引入第二彩色 accent。
